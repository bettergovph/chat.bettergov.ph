# Provider integration notes

Checked against the existing projects on this VM on 2026-09-21. These are implementation references, not additional runtime dependencies. Kuya J reads the public APIs; it does not read the sibling projects' databases or credentials.

| Project | Files inspected | Integration consequences |
| --- | --- | --- |
| `../legalhub` | `worker/handlers/mcp.ts` | Semantic searches return discovery records. Exact cases/Republic Acts support `include_full_text`; fetching it can fail independently, so its presence must be checked. Section summaries may be incomplete. Prefer `source_url` for authoritative text. Preserve full text and provenance before large summary arrays when compacting evidence. |
| `../bataswatch` | `worker/handlers/mcp.ts`, `shared/domain/bills.ts`, `shared/domain/discovery.ts` | Use `browse_bills` for catalog discovery, semantic search for analyzed records, and `get_bill(include_text: true)` for provisions. Keep congress, chamber, document version, extraction status and verification dates. `listed_author` does not establish principal authorship. Recognize `officialRecordUrl` and version `sourceUrl` citations. |
| `../psa` | `lib/api-http.mjs`, `lib/public-api.mjs`, `lib/classification-api.mjs`, `lib/classification-spec.mjs`, `scripts/classification/catalog.mjs` | Fetch metadata and dimension values before querying observations with an exact release and selection. Preserve units, source and snapshot dates. Classification filters are system-specific, support documented aliases, and preserve leading zeros. Follow the catalog or `manifest.json`; PSGC has no `all` route. Tourism paths are unversioned but still paginated. |
| `../floodlens-ph` | `src/worker.js` | Project search is restricted to geocoded flood-control projects. `q` matches one substring across indexed fields. `bbox` is west/south/east/north. The handler ignores offset and always reports offset zero: there is no pagination. Narrow the query or bounding box; do not sum a sample as national expenditure. |
| `../dynasty` | `worker/index.ts` | MCP and REST expose election histories, contests, coverage and surname blocs. REST uses `candidates=1`, `members=1` and `min`, while MCP uses booleans and `min_members`. Keep election years, vote-link provenance and identity confidence. These records do not establish current officeholders or kinship. |
| `../ai-reports` | `src/worker/mcp.ts`, `src/worker/public-api.ts` | Budget amounts are pesos. GAA, NEP and execution stages are distinct; cycle coverage is limited. Preserve cursors, totals and omitted-row notices. REST citation equivalents map `query` to `q`, rollup `by_department` to `by=department`, and transcript ranges to `from`/`to`. Hearing figures are spoken/transcribed statements. |
| `../bettergov-v2` | `scripts/index_meilisearch.cjs`, `src/components/search/MeilisearchInstantSearch.tsx`, `src/data/services/schema/services.schema.json` | All records share the `bettergov` index. Types are `service`, `directory_item`, and `website`. Service visibility is `published=true`; query with a publication filter plus an optional typed filter. Agency titles can be `office_name` or `office`; records can link through `website` or the canonical directory slug. |

The adapter mappings live in `lib/server/provider-contracts.ts`; tool execution lives in `lib/server/tools.ts`. Citation extraction in `lib/server/evidence-links.ts` prefers API-returned knowledge-base record URLs over original-document fields. Juris returns `/case/:id` and `/republic-act/:id`; BatasWatch returns `/bills/:chamber/:number` and `/authors/:chamber?author=...`. BatasWatch detail responses put the page URL on the outer object, so nested discovery records and document versions inherit it. Original-document URLs are retained as provenance, not separate primary citations when a record page exists. Regression cases are in `tests/providers.test.ts`.

Observation queries use POST and cannot be reproduced by opening a GET citation alone. PSA metadata, dimension-value and observation citations all point to `/datasets/:id`; searches prefer each returned dataset's page rather than adding an aggregate API citation. The evidence retains the release and exact selection. Precise lookup URLs preserve GET filters in provenance and Debug, while public navigation uses available pages or a main-site fallback. See [public citation mappings](public-citations.md). MCP result limits are bounded to 30, including omitted limits whose upstream defaults are much larger. Long evidence is explicitly labeled when abbreviated; it cannot establish completeness.

The ASEAN country-catalog citation was also verified against `GET https://asean.bettergov.ph/api/v1/countries`.
